Política de Privacidade

Última atualização: 8 de novembro de 2026.

O aplicativo Videos Automatizados é uma ferramenta de uso próprio que publica vídeos em Páginas do Facebook administradas pelo seu responsável.

Dados que usamos

O aplicativo acessa somente os dados necessários para publicar nas Páginas do próprio responsável: nome e identificador da Página e o token de acesso concedido pela Meta. Ele não coleta nem armazena dados pessoais de seguidores ou visitantes das Páginas.

Como usamos e guardamos

Essas informações servem apenas para enviar e publicar vídeos. Os tokens de acesso ficam guardados no computador do responsável e não são vendidos nem compartilhados com terceiros. A publicação é feita pela API oficial da Meta.

Exclusão de dados

O acesso pode ser revogado a qualquer momento nas configurações de Integrações comerciais do Facebook. Para solicitar a exclusão de qualquer dado relacionado a este aplicativo, escreva para o contato abaixo.

Contato
